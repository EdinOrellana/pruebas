1. COMPONENTE: StatCard & StatGrid (Tarjetas KPI)
================================================================================
Archivos: frontend/src/components/common/StatCard.tsx

DESCRIPCIÓN:
Conjunto modular para renderizar tarjetas de métricas o indicadores clave (KPI) 
con borde izquierdo coloreado de 4px, título superior, ícono de Lucide a la derecha, 
cifra destacada en tipografía monoespaciada (con color personalizable) y subtítulo descriptivo inferior.

PROPIEDADES (PROPS) - StatCard:
- label (string) [Obligatorio]: Título o etiqueta superior de la métrica.
- value (ReactNode) [Obligatorio]: Valor numérico o monto a desplegar en grande.
- subtitle (string) [Opcional]: Texto explicativo inferior (ej. "En fondos operativos en sucursales").
- icon (LucideIcon | ReactNode) [Opcional]: Componente de ícono de Lucide (Wallet, Users, CheckCircle2, etc.).
- color ("accent" | "success" | "warning" | "danger" | "teal" | "purple" | "neutral") [Opcional]: Color del borde e icono (Default: "accent").
- valueColor ("accent" | "success" | "warning" | "danger" | "teal" | "purple" | "neutral" | "primary" | string) [Opcional]: Color personalizado para la cifra.
- className (string) [Opcional]: Clases CSS adicionales.
- style (React.CSSProperties) [Opcional]: Estilos inline para el contenedor.

PROPIEDADES (PROPS) - StatGrid:
- children (ReactNode) [Obligatorio]: Tarjetas StatCard a contener.
- className / style [Opcional]: Estilos o clases para el grid responsivo (auto-fit minmax 220px).

EJEMPLO DE IMPLEMENTACIÓN:
```tsx
import { Wallet, CheckCircle2, Building2, Users } from "lucide-react";
import { StatGrid, StatCard, fmt } from "../../components/common";

<StatGrid>
  <StatCard
    label="Fondo Total Activo"
    value={fmt(59000)}
    subtitle="En fondos operativos en sucursales"
    icon={Wallet}
    color="accent"
  />
  <StatCard
    label="Cajas Chicas Activas"
    value={14}
    valueColor="success"
    subtitle="De 16 registradas en el catálogo"
    icon={CheckCircle2}
    color="success"
  />
  <StatCard
    label="Promedio por Caja"
    value={fmt(4214.29)}
    subtitle="Por sucursal con caja abierta"
    icon={Building2}
    color="teal"
  />
  <StatCard
    label="Custodios Asignados"
    value={14}
    valueColor="purple"
    subtitle="Empleados con asignación de fondo"
    icon={Users}
    color="purple"
  />
</StatGrid>
```

2. COMPONENTE: StatusBadge (Badges de Estado Tipo Píldora)
================================================================================
Archivo: frontend/src/components/common/StatusBadge.tsx

DESCRIPCIÓN:
Insignia semántica tipo píldora redondeada (border-radius 9999px) con indicador 
de viñeta '●' (activo / gasto / reposición) u '○' (inactivo / anulado), fondo suave con 
transparencia del 12%-14% y texto en negrita según el estado del registro.

MAPEO AUTOMÁTICO DE ESTADOS:
- "ACTIVA" | "A"           -> Fondo verde menta, texto verde (#10b981), símbolo '● ACTIVA'
- "INACTIVA" | "I"         -> Fondo rojo pastel, texto rojo (#ef4444), símbolo '○ INACTIVA'
- "GASTO"                  -> Fondo rojo pastel, texto rojo (#dc2626), símbolo '● GASTO'
- "REPOSICION" | "REPOSICIÓN" -> Fondo verde menta, texto verde (#059669), símbolo '● REPOSICIÓN'
- "ANULADO" | "ANULADA"    -> Fondo gris neutro, texto gris (#64748b), símbolo '○ ANULADO'
- "PENDIENTE"              -> Fondo ámbar pastel, texto naranja (#d97706), símbolo '● PENDIENTE'

PROPIEDADES (PROPS):
- status (string) [Obligatorio]: Código o texto del estado.
- label (string) [Opcional]: Texto alternativo a mostrar.
- dot (boolean) [Opcional]: Mostrar viñeta '●' u '○' (Default: true).
- color ("success" | "danger" | "warning" | "neutral" | "accent" | "purple") [Opcional]: Sobrescribir color automático.

EJEMPLO DE IMPLEMENTACIÓN:
```tsx
import { StatusBadge } from "../../components/common";

<StatusBadge status="ACTIVA" />
<StatusBadge status="INACTIVA" />
<StatusBadge status="GASTO" />
<StatusBadge status="REPOSICION" />
<StatusBadge status="ANULADO" />
```

3. COMPONENTE: Pagination
================================================================================
Archivo: frontend/src/components/common/Pagination.tsx

DESCRIPCIÓN:
Componente modular que centraliza la navegación por páginas, selector de 
registros por página (10, 15, 20, 25, 30), indicador de rango ("Mostrando X a Y de Z") 
y botones Anterior/Siguiente con estados deshabilitados automáticos.

PROPIEDADES (PROPS):
- paginaActual (number) [Obligatorio]: Número de la página activa (1-indexed).
- totalPaginas (number) [Obligatorio]: Total de páginas calculadas.
- totalRegistros (number) [Obligatorio]: Total de registros totales o filtrados.
- limitePorPagina (number) [Obligatorio]: Cantidad de elementos por página.
- onCambioPagina ((pagina: number) => void) [Obligatorio]: Callback al cambiar de página.
- onCambioLimite ((nuevoLimite: number) => void) [Opcional]: Callback al cambiar selector de límite.
- opcionesLimite (number[]) [Opcional]: Array de opciones (Default: [10, 15, 20, 25, 30]).
- etiquetaRegistros (string) [Opcional]: Nombre de la entidad (Default: "registros").
- loading (boolean) [Opcional]: Deshabilita los botones durante cargas activas.

EJEMPLO DE IMPLEMENTACIÓN:
```tsx
const [paginaActual, setPaginaActual] = useState(1);
const [limitePorPagina, setLimitePorPagina] = useState(10);

const totalRegistros = datosFiltrados.length;
const totalPaginas = Math.ceil(totalRegistros / limitePorPagina) || 1;

// Segmento paginado visible en la tabla:
const datosPaginados = useMemo(() => {
  const inicio = (paginaActual - 1) * limitePorPagina;
  return datosFiltrados.slice(inicio, inicio + limitePorPagina);
}, [datosFiltrados, paginaActual, limitePorPagina]);

return (
  <Pagination
    paginaActual={paginaActual}
    totalPaginas={totalPaginas}
    totalRegistros={totalRegistros}
    limitePorPagina={limitePorPagina}
    onCambioPagina={setPaginaActual}
    onCambioLimite={(limite) => {
      setLimitePorPagina(limite);
      setPaginaActual(1);
    }}
    loading={loading}
    etiquetaRegistros="movimientos"
  />
);
```

8. COMPONENTE: SearchableSelect (con Iconos Integrados)
================================================================================
Archivo: frontend/src/components/common/SearchableSelect.tsx

DESCRIPCIÓN:
Selector inteligente tipo combobox con búsqueda predictiva interna en tiempo real, 
soporte de íconos temáticos en opciones y trigger, tooltip emergente (?) en la etiqueta 
y formato en dos líneas (código/nombre y detalle).

PROPIEDADES (PROPS):
- label (string) [Obligatorio]: Etiqueta del campo.
- value (number | string) [Obligatorio]: ID o clave seleccionada.
- options (SelectOption[]) [Obligatorio]: Opciones a desplegar.
  * id (number | string): Identificador único.
  * codigo (string) [Opcional]: Código tipo badge (ej. "SUC-001").
  * nombre (string): Nombre principal.
  * detalle (string) [Opcional]: Texto descriptivo secundario.
  * icon (LucideIcon | ReactNode) [Opcional]: Ícono a desplegar junto al elemento.
- onChange ((val: number | string) => void) [Obligatorio]: Callback de selección.
- tooltip (string) [Opcional]: Hint en hover sobre '?'.
- required / disabled / error [Opcionales].

EJEMPLO DE IMPLEMENTACIÓN:
```tsx
import { Building2 } from "lucide-react";
import { SearchableSelect } from "../../components/common";

const sucursales = [
  {
    id: 1,
    codigo: "SUC-001",
    nombre: "Sucursal Central Zona 1",
    detalle: "Fondo Asignado: Q 5,000.00",
    icon: Building2
  }
];

<SearchableSelect
  label="Sucursal / Caja Chica"
  value={cajaSeleccionada}
  options={sucursales}
  onChange={(val) => setCajaSeleccionada(Number(val))}
  tooltip="Selecciona la caja chica correspondiente a la sucursal que emite el gasto."
  required
/>
```

9. COMPONENTE: FormField (con HintTooltip Integrado)
================================================================================
Archivo: frontend/src/components/common/FormField.tsx

DESCRIPCIÓN:
Campo universal de entrada de texto, números o fechas, con soporte automático de 
tooltip '?' en la etiqueta (evitando textos inferiores saturantes), borde rojo en caso 
de error y estado de solo lectura.

PROPIEDADES (PROPS):
- label (string) [Obligatorio]: Etiqueta del campo.
- tooltip (string) [Opcional]: Muestra el ícono '?' con tooltip en hover.
- error (string) [Opcional]: Mensaje de error en color rojo.
- required / disabled / readOnly [Opcionales].

EJEMPLO DE IMPLEMENTACIÓN:
```tsx
<FormField
  label="Monto del Movimiento (Q)"
  type="number"
  value={monto}
  onChange={(e) => setMonto(e.target.value)}
  tooltip="Importe en Quetzales del gasto o reposición sin exceder el saldo disponible."
  placeholder="0.00"
  required
/>
```
